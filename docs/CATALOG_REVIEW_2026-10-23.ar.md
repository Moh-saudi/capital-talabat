## عرض التطبيق والتوافر

- `catalogItems.showInApp` مستقل عن `available`؛ إخفاؤه يحفظ إعدادات عروض التجار وأسعارهم.
- تنسخ عروض التجار الحقل إلى `products.showInApp`، مع إيقاف `inStock` في الإسقاط عند إخفاء الهوية.
- المنتجات القديمة التي لا تحتوي الحقل تعامل كظاهرة حفاظًا على التوافق.
- صفحة الكتالوج العامة واشتراك Flutter يستبعدان `showInApp:false`.
- خادم إنشاء الطلبات يرفض المنتج المخفي حتى لو أرسل العميل معرفًا قديمًا له.
- تعديل Flutter يحتاج إعادة بناء ونشر التطبيق؛ نسخة الهاتف المثبتة سابقًا لا تكتسب سلوك الحقل تلقائيًا. أدوات Flutter/Dart غير متاحة في بيئة العمل، فلم يُنفّذ تحليل أو بناء Flutter هنا.
- الهوية المشتركة وحدها ليست عرض متجر: حتى عند اختيار الظهور، يلزم عرض تاجر بصورة وسعر وكمية وحالة صالحة ليظهر منتج قابل للبيع.

## تفاصيل العرض

`promotion` كائن اختياري، و`promoted` تفعيل الحملة على الهوية (`hasPromotion` في المنتج السابق):

```ts
{
  title: string,
  occasion: string,
  startsAt: string, // ISO UTC
  endsAt: string,   // ISO UTC
  couponCode: string,
  terms: string
}
```

الضغط على مربع «عليه عرض» يفتح نافذة التفاصيل. عنوان وتاريخا بداية ونهاية صالحان مطلوبون؛ المناسبة والكوبون والشروط اختيارية. النافذة تعرض قيمة وحدّ الكوبون المختار من القائمة المحمّلة. الخادم يتحقق من وجود الكوبون قبل الحفظ. يمكن تعديل العرض أو إلغاؤه من النافذة. الأخطاء تبقي النافذة مفتوحة.

لا تُغيّر الحملة السعر أو تنشئ كوبونًا تلقائيًا. الخصم الحالي يُطبق على السلة وفق إعدادات الكوبون القائمة. **ربط الكوبون بالحملة لا يحصر استخدامه في هذا الصنف ولا يغيّر صلاحيته الزمنية**؛ ذلك يحتاج تطوير سياسة تسعير/كوبونات مخصصة. مناسبة بلا كوبون حملة تعريفية فقط.

الإسقاط يحفظ بيانات الجدولة؛ `hasPromotion/badge` صورة للحالة وقت تحديثه. Getter الشارة في Flutter يحسب الفترة الحالية عند القراءة، ليخفي الشارة خارج المدة ويعرض عنوان الحملة داخلها. حساب الوقت ليس مؤقتًا يعيد رسم كل الشاشات عند الدقيقة نفسها؛ يظهر التغيير عند إعادة البناء/القراءة أو وصول تحديث. العلامات القديمة بلا كائن تفاصيل تبقى متوافقة.
